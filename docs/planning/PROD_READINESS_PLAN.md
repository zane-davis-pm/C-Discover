## 1. CRITICAL — Leaked Census API key (do this first)

`.env.local` contains a live `CENSUS_API_KEY` and is **tracked in git in every commit**. `.gitignore` does not exclude it. Anyone who receives this repo (or its git history) gets the key.

Steps:

1. **Rotate the key.** Request a new one at https://api.census.gov/data/key_signup.html and treat the old one as burned.
2. Add `.env.local` (and `.env*` generally) to `.gitignore`.
3. `git rm --cached .env.local` and commit.
4. **Purge it from history.** There is no remote yet, so this is cheap. Either:
   - `git filter-repo --invert-paths --path .env.local` (clean), or
   - squash all history into a single fresh commit if history isn't worth keeping.
5. Create `.env.example` with `CENSUS_API_KEY=` (blank) so the pipeline's env requirement is documented without the value.
6. Send the new key to the Azure engineer out-of-band (password manager / secret share — not in the repo, not in email with the files). In GitHub, it goes in repo secrets as `CENSUS_API_KEY` — the refresh workflow already reads it correctly from `secrets.CENSUS_API_KEY`.
